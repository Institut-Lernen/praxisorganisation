Excel-Export

Erzeugt die vier Original-Excel-Dateien (gleiche Struktur wie deine Vorlagen) aus den App-Daten. Im finalen Produkt ersetzt die Microsoft-Graph-Sync diesen manuellen Schritt.

Hinweis: Im Prototyp werden die Daten lokal im Browser (localStorage) gespeichert. In der Produktiv-App liegt die Excel in OneDrive/SharePoint und wird via Microsoft Graph API synchronisiert – damit mehrere Therapeut:innen gleichzeitig arbeiten können.

Import / Backup

Tipp: Setze ein Backup-Passwort, dann wird die JSON-Datei AES-256-verschlüsselt gespeichert. Ohne Passwort ist die Datei unverschlüsselt (alte Backups bleiben lesbar).

Verschlüsselte Backups erkennst du am Dateinamen-Zusatz .enc.json und am inneren Format praxisorg-encrypted-v1. Beim Laden wird das Passwort abgefragt.

🔐 Rollen-Zugriffspasswörter (nur Leitung)

Damit eine Honorarkraft oder Therapeut:in nicht einfach „Leitung" auswählen kann, lege hier Passwörter für die beiden anderen Rollen fest. Die Rolle Leitung bleibt passwortfrei (Standard für dich als Inhaberin). Passwörter werden mit PBKDF2-SHA-256 (200.000 Iterationen) gehasht gespeichert — niemand kann sie aus den App-Daten zurückrechnen.

Alles löschen
